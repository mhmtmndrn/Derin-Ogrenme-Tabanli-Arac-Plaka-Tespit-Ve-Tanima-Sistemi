# Model Dosyalari

Bu proje iki model dosyasi kullanir:

```text
models/plate_detector.pt
models/plate_reader.pt
```

- `plate_detector.pt`: arac gorselindeki plaka bolgesini tespit eder.
- `plate_reader.pt`: kirpilmis plaka gorselindeki karakterleri okur.

Varsayilan toplu calistirma komutu bu iki dosyayi kullanir:

```powershell
python run_all_images.py
```
